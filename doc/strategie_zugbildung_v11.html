Strategie: Programmatische Zuordnung von Modellzuggarnituren

"Jeder der Zugbildungspläne (Zp) enthält eine Wagenreihung, wie sie beim Vorbild geplant ist. Für die Umsetzung im Modell stehen einerseits nicht alle Wagentypen zur Verfügung, andererseits gibt es feste Zuggarnituren mit festen Wagenreihungen - und zwar weniger und andere, als es die Zugbildungspläne vorsehen. Somit ist im Modus "Modellreihung" für jeden Vorbild-Zp eine passende Modellzuggarnitur zu finden. Ideal ist die exakte Übereinstimmung. Wenn das nicht möglich ist, soll die bestmöglich passend Zuggarnitur vorgeschlagen werden. Das Dokument beschreibt eine Strategie, diesen Vorschlag programmatisch umzusetzen"

1. Regelwerk und Metriken

Um die "bestmöglich passende" Zuggarnitur zu ermitteln, wird ein erweitertes Scoring-System eingeführt. Die Eigenschaften der Wagen aus zpa.csv und den Modellgarnituren werden anhand folgender Kriterien bewertet:

Achszahl

Harte Bedingung (K.O.-Kriterium)

Enthält die Gattung eine "4" (z.B. AB4ü), hat der Wagen 4 Achsen. Fehlt die "4" (z.B. Pw), hat er 2 Achsen. Regel: Beim Abgleich zweier Wagen muss die Achszahl strikt identisch sein. Eine Abweichung ist unzulässig.

Hauptgattung

Weiche Bedingung (Scoring)

Die primären Typen (A, B, C, WR, WL, Post, Pw, S) werden isoliert betrachtet. Regel: Jede getroffene Hauptgattung erhöht den Ähnlichkeitswert (Score).

Bauart (Länder- vs. Einheitsbauart)

Präferenz-Kriterium

Analyse des Zusatzes nach dem Bindestrich -. Neben Ausland und FD-Zügen verwenden nun auch explizite Züge wie D39 und D40 (erweiterbar) bevorzugt Einheitsbauarten. Für Bayern / Württemberg greifen entsprechende Länderbauarten.

Reihenfolge & Spiegelung

Weiche Bedingung (Scoring)

Die Abfolge der Wagen ist maßgeblich. Da Modellzüge gewendet werden können, ist eine Spiegelung zulässig. Regel: Analyse vorwärts und gespiegelt. Das bessere Resultat zählt.

4. Algorithmus (inkl. spezifischer Einheitszug-Regel)

FUNCTION ErmittleBauartPraeferenz(zug_info):
    zug_nr = zug_info.zug_nr
    ziel_bf = zug_info.von IF zug_info.von != "Berlin" ELSE zug_info.nach
    
    # NEU: Konkrete Züge, die bevorzugt Einheitsbauarten verwenden (erweiterbare Liste)
    einheits_zuege = ["39", "40", "D39", "D40"]
    IF zug_nr IN einheits_zuege:
        RETURN { typ: "EINHEIT", erlaubte_zusätze: [] }
        
    IF zug_info.is_fd:
        RETURN { typ: "EINHEIT", erlaubte_zusätze: [] }
        
    AUSLAND = ["Österreich", "Schweiz", "Tschechien", "Slowakei", "Wien", "Zürich", "Basel", "Chur", "Ventimiglia"]
    IF ziel_bf IN AUSLAND:
        RETURN { typ: "EINHEIT", erlaubte_zusätze: [] }
        
    BW = ["Stuttgart", "Karlsruhe", "Singen", "Mannheim", "Freiburg", "Konstanz"]
    IF ziel_bf IN BW:
        RETURN { typ: "LAENDERBAUART", erlaubte_zusätze: ["württ"] }
        
    BAYERN = ["München", "Nürnberg", "Augsburg", "Regensburg"]
    IF ziel_bf IN BAYERN:
        RETURN { typ: "LAENDERBAUART", erlaubte_zusätze: ["bay", "pr"] }
        
    RETURN { typ: "LAENDERBAUART", erlaubte_zusätze: ["pr"] }
